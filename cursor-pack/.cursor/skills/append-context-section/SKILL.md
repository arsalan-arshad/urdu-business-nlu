# Append a context section

1. Read `PROJECT_CONTEXT.md` fully. It is append-only: never rewrite history.
2. Add the next numbered section at the end, titled `## N. Session update: <topic> (<YYYY-MM-DD>)`. Content: what was done, what was found (with evidence paths), decisions made by the owner (D1 to D5), what was superseded.
3. If an earlier section is now wrong, edit only a marker on it: "superseded by section N". Do not delete it.
4. Update the snapshot line at the top (date, phase, one-line status).
5. Update the punch list: move resolved items to Resolved (terse), keep Open items specific enough to act on.
6. No secrets, no real messages, no phone numbers, no audio references. Contact email stays arsalanarshad.dev@gmail.com.
7. Never record an owner decision the owner did not make. Suggestions are labelled "suggested".
