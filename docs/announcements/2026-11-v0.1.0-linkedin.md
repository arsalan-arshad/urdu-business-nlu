Shipped **urdu-business-nlu** v0.1.0 — an MIT TypeScript library for informal Urdu / Roman-Urdu / mixed-English business messages (orders, payments, udhaar, delivery).

**What it is:** rules-only `propose` → deterministic validator → `auto` | `confirm` | `reject`. Silent-error focus: prefer a confirm over a wrong quantity or amount. Optional LLM is BYOK and later — not in this release.

**What it is not:** not a WhatsApp bot, not Meta Business API, not a ledger, not a hosted SaaS. No marketing accuracy percentages — cite the eval reports in the repo if you need numbers.

M3 decision: **GO** for rules-only v0. Install and dig in:

```
npm i urdu-business-nlu
```
